ARA EMAIL MAGIC-LINK SIGN-IN

This version uses Supabase passwordless email Magic Links (customers click a link; they do not enter a code).

Included: account.html and account.js updated for Magic Link sign-in and callback handling. The rest of the ARA storefront, cart, thank-you/order tracking pages, and unified admin portal are retained.

Supabase setup:
1. Open Supabase Dashboard > Authentication > URL Configuration.
2. Set Site URL to https://arapcb.com (or your actual production domain).
3. Add https://arapcb.com/account.html to Redirect URLs. Add your local development URL only if you use one.
4. Authentication > Providers > Email: ensure email sign-in is enabled.
5. Keep the Magic Link email template enabled. The default clickable sign-in link template is appropriate. No custom SMTP is required just to test, but the default sender has rate limits.
6. Deploy the complete folder to your hosting provider and test with an email you can access.

Important:
- The account page uses signInWithOtp({ email, options: { shouldCreateUser: true, emailRedirectTo } }) and completes the callback if Supabase returns a PKCE code.
- If your Supabase project is configured to send numeric OTP codes instead of clickable links, this website's sign-in experience will not match the template; keep the default Magic Link template for this build.
- My Orders queries only rows linked to the signed-in auth user via orders.user_id. You must update the database schema/RLS and checkout Edge Function to associate new orders with auth.users.id before account order history can work. Do not expose all orders publicly.
- Do not put a Supabase service-role/secret key in any browser-side file.
